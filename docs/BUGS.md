reclassified. Every row has a `status` (exactly one of `open` / `fixed` /
`wontfix` / `d14-legit` / `duplicate`) and a `cluster` (`semantics` /
`real-app` / `deps` / `passes` / `emit-shape` / `harness` / `toolchain` /
`metrics`). Every **open** row must carry a `cluster`, a one-line `verdict`
(what would prove it fixed — a fixture, a test, or a measurement — and which
`docs/QUEUE.md` item or lane owns it), and an `owner`. Every **resolved**

row, or a deliberate design choice). New bugs are appended to Open with a
`cluster` and `verdict` from the start — no more thin "why no test yet"
